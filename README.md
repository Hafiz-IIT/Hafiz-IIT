## Flagship: EXIM AI — Evidence-Gated Autonomy

The flagship research direction studies whether an AI decision should **ACT, VERIFY, REQUEST EVIDENCE, DEFER, or ESCALATE** when evidence is incomplete, conflicting, stale, correlated, or potentially adversarial.

The repository contains executable research artifacts and explicit claim boundaries. It is not presented as a production customs system, a deployed scanner, or a regulatory integration.

## Engineering and research standard

I distinguish:

**Concept → Architecture → Implementation → Tested → Reproducible → Experimentally validated → Externally validated → Deployed**

A design is not described as an implementation; a synthetic result is not described as real-world validation; a manuscript scaffold is not described as a publication.
